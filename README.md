# devops25 CI/CD

## Dag 1 – Git-övning

Under den första dagen har jag klonat projektet från GitHub, konfigurerat en virtuell Python-miljö och startat FastAPI lokalt för att testa applikationens endpoints. Jag har även skapat en separat Git-branch för att hantera ändringar utan att påverka huvudgrenen. Syftet med övningen är att få en praktisk förståelse för versionshantering med Git, samarbete via GitHub och hur dessa delar ingår i ett CI/CD-arbetsflöde.
